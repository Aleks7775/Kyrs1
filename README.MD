# Финансовый сервис

## Описание
Этот проект представляет собой финансовый аналитический сервис,
который предоставляет пользователю возможность анализировать свои расходы,
доходы, отслеживать курсы валют и цены акций
## Установка
1. Клонируйте репозиторий:

```
git clone https://github.com/
```
2. Перейдите в директорию проекта:
```
cd ваш_проект
```
3. Установите необходимые зависимости:
```
pip install -r requirements.txt

poetry add --group dev pytest

poetry add pandas

poetry add openpyxl
```

# Основные функции
# Веб-страницы:
Выводит данные для анализа и вывода на веб-страницах -  это данные 
с начала месяца, на который выпадает входящая дата, по входящую дату.
1. Приветствие в формате "???", где ??? — «Доброе утро» / «Добрый день» /
«Добрый вечер» / «Доброй ночи» в зависимости от текущего времени.
2. По каждой карте: последние 4 цифры карты; общая сумма расходов;
кешбэк (1 рубль на каждые 100 рублей).
3. Топ-5 транзакций по сумме платежа.
4. Курс валют.
5. Стоимость акций из S&P500.

# Сервисы
Сервис позволяет проанализировать, какие категории были наиболее выгодными
для выбора в качестве категорий повышенного кешбэка.

# Отчеты
Функция возвращает траты по заданной категории за последние три месяца
(от переданной даты).
